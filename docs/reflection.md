# Engineering reflection

AI-assisted draft for the submitter to review: the useful finding in this work was how easily passing Go tests could be mistaken for evidence about a PostgreSQL race. In this environment, the real database tests skipped and five requested experiment invocations stopped at preflight, even though unit tests and single-user SQL checks passed. Making those distinctions explicit led to saved manifests, raw events, failed-run summaries, and an independent audit that rejects deliberately corrupted fixtures. The remaining concern is the gap between the transaction design and observed behavior under real concurrent crashes and load; the current DON'T SHIP verdict reflects that gap. This paragraph describes observed outcomes, not an invented personal reaction or a claim of independent human verification.
